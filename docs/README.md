## 文档分工

本仓库维护通用机制的唯一解释。IAM 维护权限版本与失效策略，QS 维护答卷、评估、报告、Task 等领域链路，qs-ai 维护持久接单、执行、冻结配置和模型结果恢复。具体地图见[宿主接入边界](02-接入指南/宿主接入边界.md)。

[候选与待决问题](proposals/ai-mq.md)不等同已采用合同。[历史归档](_archive/README.md)保留形成过程和失败证据；日常接入不需要先阅读它。旧文档路径仍保留迁移指引，不再累计阶段流水账。
